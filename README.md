## 代表项目

### [Project Mystery](https://github.com/Herdeny/Lord-of-Mysteries)

基于 Minecraft Forge 1.20.1 的生存冒险 Mod，围绕魔药、序列、调查、仪式、封印物与失控风险构建完整玩法系统。项目重视状态一致性、失败恢复、自动化验证和长期维护。

### [MySpeed macOS](https://github.com/Herdeny/MySpeed-MacOS)

面向 Apple Silicon 与 Intel Mac 的原生菜单栏网络质量监测工具，支持定时测速、长期记录和多测速服务，无需 Docker。

### [HealthAI](https://github.com/Herdeny/HealthAi)

### [BigData](https://github.com/Herdeny/BigData)

围绕数据处理、分析与应用展示完成的大数据实践项目，使用 Python 构建从原始数据到可用结果的完整流程。
