### 🔬 Undergraduate Thesis / 本科毕业设计

**面向血液组学数据的多视角图表示学习方法**  
*Multi-view Graph Representation Learning Methods for Blood Omics Data*

面向具有不同视角和结构的血液组学数据，探索如何利用图表示学习建立多源数据之间的关联，并获得适用于下游任务的统一表示。

This work explores graph-based representations that connect heterogeneous views of blood omics data and support downstream learning tasks.
